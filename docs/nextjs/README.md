# Next.js App Router Reference (v16.3.3, verified 2026-08-29)

Condensed, LLM-oriented notes from https://nextjs.org/docs (index: https://nextjs.org/docs/llms.txt).
Documented version: **Next.js 16.3.3** (latest stable; 16.x is the current major, 15.5.x is LTS).

Key Next 16 changes to remember:
- `middleware.ts` is renamed **`proxy.ts`** (export `proxy`); Node.js runtime.
- Caching model is **Cache Components** (`cacheComponents: true`) with `'use cache'`, `cacheLife`, `cacheTag`, `revalidateTag(tag, 'max')`, `updateTag`, `refresh`. No implicit fetch caching.
- `params` / `searchParams` are **Promises** (must `await`).
- `error.tsx` receives `{ error, retry }` (formerly `reset`); `catchError` from `next/error` for component-level boundaries.
- Global type helpers `PageProps<'/route'>`, `LayoutProps<'/route'>`, `RouteContext<'/route'>` (generated by `next dev|build|typegen`).
